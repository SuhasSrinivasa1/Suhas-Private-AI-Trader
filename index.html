Security rules

  • Never store passwords, OTPs, PINs, TOTP seeds, recovery codes, or bank logins.
  • Use official broker APIs only.
  • Store credentials in backend/.env, never in browser JavaScript or GitHub.
  • Local AI receives only the selected trade snapshot—not broker credentials.
  • Keep order placement behind backend guardrails and human confirmation.
  • Rotate any credential exposed outside its intended secret store.
